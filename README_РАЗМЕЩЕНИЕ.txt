AIQ BASE — САЙТ + ПРИЛОЖЕНИЕ

www/index.html — презентационный сайт
www/app/index.html — существующее приложение (без изменения основной логики)
www/app/manifest.webmanifest, service-worker.js, icons/ — файлы установки веб-приложения

Для веб-хостинга опубликуйте содержимое www/ в корне домена aiqbase.app. Тогда сайт откроется на /, приложение на /app/. HTTPS обязателен для установки.

ВАЖНО ДЛЯ ANDROID CAPACITOR: текущая Android-конфигурация может использовать webDir=www. НЕ выполняйте sync android на этой сборке сайта, пока не подготовлена отдельная папка сборки Android с приложением в корне (или не перенастроен процесс сборки). Иначе Android запустит презентационный сайт вместо приложения.

Пример синхронизации только после настройки отдельного Android webDir:
cd "C:\Users\User\Downloads\AIQ Base"
npx cap sync android

Данные: локальное хранилище веб-браузера и Android не синхронизируется автоматически. Для синхронизации нужен серверный аккаунт и база.
