AIQ BASE — GitHub Pages, только презентационный сайт и необходимые служебные страницы.

ЗАГРУЗКА: файлы ИЗ ЭТОГО АРХИВА разместить в КОРНЕ репозитория, без дополнительной папки.
index.html должен лежать непосредственно в корне выбранной ветки GitHub Pages.

СОСТАВ:
index.html — новый премиальный сайт из AIQ Base Website.zip.
privacy-policy.html, terms.html, support.html — существующие публичные юридические и служебные страницы.
styles.css, icons/icon-192.png — стили и значок для этих старых страниц.
auth-callback/index.html, reset-password/index.html — существующие веб-страницы подтверждения почты и сброса пароля. Это НЕ файлы Android-приложения, но их удаление может нарушить авторизацию, если приложение использует адреса aiqbase.app/auth-callback/ и /reset-password/.
robots.txt — разрешение индексирования.

НЕ ВКЛЮЧЕНЫ: app_preview.html, content/, institution/, qa/, service-worker.js, manifest.webmanifest и Android/Capacitor.
Старый service worker при открытии новой главной страницы снимается с регистрации, чтобы не показывать устаревший сайт.

ВАЖНО: перед полным удалением репозитория проверьте в настройках авторизации, что callback и reset-password остаются по тем же адресам.
Если Android-приложение загружает content/*.json с aiqbase.app, удаление content/ НАРУШИТ эту загрузку. Архив не может гарантировать независимость приложения от сайта без проверки конфигурации и сетевых запросов приложения.
Также сохраните настройки GitHub Pages, DNS и CNAME (если есть в репозитории или настроены отдельно).
Ссылки Google Play / App Store в сайте пока отключены, пока нет официальных URL.
